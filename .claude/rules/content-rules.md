## Long-Form Article Structure

Every blog article follows this architecture:

```
1. HOOK (1–3 paragraphs)
   - Contrarian opening claim
   - The mistake most people make
   - The promise: here's the better lens

2. FRAME THE MODEL (1 section)
   - Name the framework
   - Define its components
   - Why this model matters

3. APPLY IT (2–4 sections)
   - Walk through each component
   - Real signals/symptoms at each layer
   - Tool-specific implementation
   - "Key insight:" callout per section

4. REAL-WORLD DIAGNOSTIC (1 section)
   - Before state (the broken system)
   - The diagnosis through the framework
   - The fix and why it works

5. IMPLEMENTATION (1 section)
   - Execution principles
   - Common mistakes to avoid
   - The meta-lesson

6. ACTION CLOSE
   - "Where to start" or "Here's your starting point"
   - 4–6 numbered, concrete steps
   - One closing sentence restating the big idea

7. BIO ANCHOR (long-form only)
```

## Repurpose Flow

Write one long-form article → produce 6 derivative pieces:

```
Long-form blog article (source of truth)
  ├── LinkedIn Post 1: Framework post — extract and name the model
  ├── LinkedIn Post 2: Data drop — extract the most powerful stat
  ├── LinkedIn Post 3: Story/diagnostic — extract the real-world example
  ├── X Post 1: Contrarian opener — the hook as a standalone
  ├── X Post 2: Thread — numbered breakdown of the action steps
  ├── X Post 3: Tactical micro-post — one specific thing to do
  └── YouTube Script: Expand + add screen demo or talking head
```

---

## LinkedIn Post Types (Rotate Daily)

1. **Framework post** — name a model, explain in 5–7 lines
2. **Data drop** — one stat + what it means + what to do
3. **Story/diagnostic** — problem → insight → lesson in short narrative
4. **Contrarian take** — challenge a common belief
5. **Tactical tip** — one specific action, explained clearly
6. **Thread/carousel** — multi-part numbered breakdown

Never post the same type twice back-to-back.

---

## X Post Types (Rotate Daily)

1. **Single insight** — one idea, max 280 chars
2. **Thread** — numbered breakdown, hook tweet first, 8–12 tweets
3. **Tactical micro-post** — action-first, specific
4. **Contrarian take** — challenge a belief, short and confident
5. **Quote + commentary** — stat or insight + Clinton's lens

## Content Quality Checklist

Before publishing any piece:
- [ ] Opens with a contrarian claim (not a generic statement)
- [ ] Has a named framework or model
- [ ] Uses systems language throughout
- [ ] Names specific tools where relevant
- [ ] Ends with 4–6 concrete action steps (long-form)
- [ ] Has a clear CTA
- [ ] Maps to one of the 5 content pillars
