# Skills

This directory is intentionally empty.

Skills are built organically — only when a workflow gets used 3+ times and is worth automating into a repeatable pattern.

## Pattern

Each skill gets its own folder:
```
.claude/skills/skill-name/SKILL.md
```

The SKILL.md documents:
- **Trigger** — when to use this skill
- **Inputs required** — what you need to provide
- **Steps** — the exact workflow
- **Output format** — what the skill produces
