# SOP: Repurpose Engine

One long-form blog article → 6 derivative content pieces + 1 YouTube script.

## Input → Output Map

| Output | Source in Article | Format |
|--------|-------------------|--------|
| LinkedIn Post 1 | The named framework | Framework post |
| LinkedIn Post 2 | The most powerful stat or data point | Data drop |
| LinkedIn Post 3 | The real-world diagnostic story | Story/diagnostic |
| X Post 1 | The contrarian opener | Single insight tweet |
| X Post 2 | The action steps (action close section) | Thread (numbered) |
| X Post 3 | One tactical tip from the body | Tactical micro-post |
| YouTube Script | Full article expansion + demo | See `sops/youtube-script.md` |

## Process

1. Write the long-form blog article first (source of truth). Save to `content/blog/`.
2. Read through and identify:
   - The named framework (pull for LinkedIn Post 1)
   - The single most striking stat (pull for LinkedIn Post 2)
   - The best real-world example or diagnostic (pull for LinkedIn Post 3)
   - The contrarian opener (pull for X Post 1)
   - The action steps section (pull for X Post 2)
   - One specific tactical line from the body (pull for X Post 3)
3. Produce each output using the relevant SOP.
4. Schedule across the day — stagger, don't blast all at once.

## Scheduling Cadence

All from the same source article, same day:

| Time | Channel | Content |
|------|---------|---------|
| Morning | Blog | Publish article |
| 8am | X | Post 1 — contrarian opener |
| 9am | LinkedIn | Post 1 — framework |
| 12pm | LinkedIn | Post 2 — data drop |
| 1pm | X | Post 2 — action steps thread |
| 5pm | LinkedIn | Post 3 — story/diagnostic |
| 7pm | X | Post 3 — tactical tip |

## Efficiency Rule

Never write a LinkedIn post or X post from scratch if you've already written a blog article on that topic.
The article is the source of truth. Derivative pieces pull from it — they don't reinvent it.
