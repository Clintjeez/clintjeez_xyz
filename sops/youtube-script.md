# SOP: YouTube Script Production

## Weekly Target: 1 Script

## Video Types

| Type | Format | Best Pillar |
|------|--------|-------------|
| **Framework breakdown** | Talking head — explain a model | Pillars 1, 5 |
| **Tool walkthrough** | Screen share — build something live | Pillar 2 |
| **GTM audit/teardown** | Screen share — review a real setup | Pillar 2, 3 |
| **Lifecycle case study** | Talking head intro + screen walkthrough | Any pillar |
| **Agentic workflow demo** | Screen share — ship an AI automation | Pillar 4 |

## Script Structure

```
HOOK (0–30s)
Bold claim or question. "Most SaaS founders are losing 40% of their revenue
at one stage — and they don't know which one."
Make them stop scrolling.

PROMISE (30–60s)
"By the end of this video, you'll know exactly how to [specific outcome]."
Be specific. Not "grow your business." Specific.

CONTEXT (1–2 min)
Why this matters. Frame the problem. Who this is for.
Set up the credibility: "I've seen this in X companies..."

CORE CONTENT (6–10 min)
Step-by-step. Label each step clearly.
For screen share: narrate what you're building and why.
For talking head: use the Article Architecture framework.
Include "Key insight:" moments — verbally call them out.

KEY TAKEAWAY (1 min)
"The one thing I want you to remember from this video: [distilled insight]"
Make it quotable. This is what gets clipped.

CTA (30s)
"Subscribe — I drop systems like this every week.
If you want me to build this in your business in 48 hours,
there's a link in the description. It's $366."
```

## Production Notes

- **Talking head:** Record against a clean background. Minimal cuts. Natural pace.
- **Screen share:** Record at 1080p minimum. Zoom in on key elements. Narrate every click.
- **Both:** Use chapters in the YouTube description (00:00 Hook, 01:30 Context, etc.)

## Steps

1. Choose topic and video type
2. Write full script using the structure above
3. Note which sections need screen share vs. talking head
4. Save to `content/youtube/YYYY-MM-DD-title.md`
5. Film against the script (can improvise, but script sets the structure)
