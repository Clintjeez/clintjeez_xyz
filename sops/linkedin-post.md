# SOP: LinkedIn Post Production

## Daily Target: 3 Posts

Rotate post types. Never run the same type twice back-to-back.

## Post Types

| Type | Structure | Best For |
|------|-----------|----------|
| **Framework post** | Name the model → define 3–4 components → how to apply | Pillar 1 & 5 content |
| **Data drop** | Shocking stat → what it means → what to do | Pillar 2 & 3 content |
| **Story/diagnostic** | Problem → diagnosis → lesson | Case study material |
| **Contrarian take** | Challenge a belief → why it's wrong → what's true | Pillar 1 & 4 content |
| **Tactical tip** | One specific action → why it works → how to do it | Pillar 2 content |
| **Thread/carousel** | Hook → 8–12 numbered points → CTA | Any pillar, weekly |

## Format Rules

- **Hook line:** Bold claim or provocative question. Never start with "I". Never "Excited to share."
- **Body:** Max 2 sentences per paragraph. White space between every paragraph.
- **Hashtags:** Max 3 at the end. Relevant only — no spray-and-pray.
- **CTA:** One action per post. Comment / DM / read the article / book a sprint. Never two CTAs.
- **Length:** 150–400 words for standard posts.

## Steps

1. Identify the source (blog article or standalone idea)
2. Choose the post type for this slot (check what was posted last)
3. Write the hook first — it determines if anyone reads the rest
4. Write the body in the correct format for the post type
5. Add the CTA
6. Read aloud — if it sounds like a press release, rewrite it
7. Save to `content/linkedin/YYYY-MM-DD-post-N.md`
