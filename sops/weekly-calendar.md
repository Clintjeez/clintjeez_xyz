# SOP: Weekly Content Calendar

## Monday — Plan (30 min)

1. Review last week's top-performing posts (platform analytics + PostHog)
2. Note what worked: which hooks got the most engagement, which topics drove profile visits
3. Choose this week's 2 primary topics — one per content pillar (rotate pillars weekly)
4. Map each topic: long-form article → repurpose outputs
5. Draft the week's content schedule (template below)
6. Save as `content/campaigns/weekly-calendars/YYYY-MM-DD-week.md`

## Tuesday–Friday — Execute (3 hours/day)

Daily flow:
- **90 min** — Write one long-form blog article
- **45 min** — Produce 3 LinkedIn posts from the article (follow `sops/repurpose-engine.md`)
- **30 min** — Produce 3 X posts/threads from the article
- **15 min** — Schedule all posts, respond to comments from the previous day

## Saturday — Review (30 min)

- Check: impressions, engagement rate, profile visits, link clicks, follower growth
- Identify this week's top-performing piece — note the hook and format
- Note this week's lowest-performing piece — note what didn't land
- Log one key learning in `decisions/log.md`
