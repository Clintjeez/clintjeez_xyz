# SOP: X (Twitter) Post Production

## Daily Target: 3 Posts or Threads

## Post Types

| Type | Format | Length |
|------|--------|--------|
| **Single insight** | One bold idea | Max 280 chars |
| **Thread** | Hook tweet + 8–12 numbered tweets | Hook + body |
| **Tactical micro-post** | Action-first, specific step | Max 280 chars |
| **Contrarian take** | Challenge a belief, short and confident | Max 280 chars |
| **Quote + commentary** | Stat or claim → Clinton's lens | 1–2 tweets |

## Format Rules

- **Single posts:** One idea only. Never cram two points into one tweet.
- **Thread hooks:** Bold claim or "Here's how I [X]:" or "Most [people] get [X] wrong."
- **Thread tweets:** Each tweet must stand alone — it may get quote-tweeted out of context.
- **No hashtags** unless a trending relevant topic is in play.
- **Every word earns its place.** Cut anything that doesn't add information or rhythm.

## Thread Structure

```
Tweet 1 (hook): [Bold claim or "Here's the thing about X:"]
Tweet 2: [Setup — why this matters]
Tweets 3–10: [Numbered points, one per tweet]
Tweet 11: [The meta-lesson or key insight]
Tweet 12: [CTA — follow for more / link to article / book a sprint]
```

## Steps

1. Identify source (blog article or standalone idea)
2. Choose type for this slot (rotate — don't post two singles back-to-back)
3. Write the hook or single tweet first
4. Expand if it's a thread — keep each tweet punchy
5. Cut anything that doesn't add value
6. Save to `content/x/YYYY-MM-DD-post-N.md`
